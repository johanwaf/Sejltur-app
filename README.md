# Sejltur Regnskab

Offline Android-app til at holde styr på, hvad gæster skylder efter sejlture.

## Funktioner
- Sejlture med start- og slutdato
- Personer med ankomst- og afrejsedato
- Daglige udgifter med kategorier
- Automatisk fordeling efter hvem der var ombord den dag
- Mulighed for at medregne ejeren i udgiftsdelingen
- Fast daglig sejlerpris pr. gæst
- Samlet saldo og detaljeret opdeling pr. person
- Lokal/offline lagring i WebView
- JSON-backup til telefonens Downloads-mappe

## APK via GitHub Actions
Hver push til `main` bygger automatisk en debug-APK.
Gå til **Actions → Build Android APK → seneste kørsel → Artifacts → sejltur-regnskab-debug**.
